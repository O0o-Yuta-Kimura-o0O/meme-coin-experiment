# MIKENEKO（$MIKENEKO）

日本語の表示名：三毛猫コイン

## コンセプト / ストーリー

三毛猫の「小判ちゃん」が、道で金色のコインを拾う絵本風の物語。価値はわからないけれど、まるくて、ぴかぴかで、あったかいので、ずっと大事にしている。飼い主はカトウさん。

- 合言葉：「猫にコイン」（ことわざ「猫に小判」のもじり。A coin for a cat）
- 結び：だれでもコインをつくれる時代に、このコインも生まれた。小判ちゃんは今日もコインを頭にのせておひるねしていて、それがいくらなのかは知らない。問いかけや主張はせず、情景だけで通貨の価値を考えさせる
- SEPPUKU COIN と仕組み・配分・開始時の時価総額をそろえ、名前と物語だけを変えた比較対象

## ミーム・ビジュアル

- メインキャラクター：頭に猫の顔のコインをのせた、まんまるの三毛猫「小判ちゃん」（`sites/mikeneko/public/kobanchan.webp`）
- 挿絵：水中でコインに手を伸ばして泳ぐ小判ちゃん（`swim.webp`）、ピンクのカートに乗る小判ちゃん（`cart.webp`）
- 画像の出所：OpenAI（ChatGPT）で生成（2026年11月）。OpenAI の利用規約上、出力の権利は利用者に帰属し、商用利用できることを確認済み。サイト用に、背景を透過し、色を少しパステル寄りに調整した
- 色：ピンクと白をベースにしたパステル調。サイトはスクロールに合わせて、小さな小判ちゃんが画面を走ったり飛んだりする

# SEPPUKU（$SEPPUKU）

## コンセプト / ストーリー

コンセプチュアルアートの一環として、**AI に問題を解かれてしまった数学者の悲劇**を、客観的に、少しだけ皮肉を込めて描くミームコイン。

- 切腹という悲壮な古い日本文化をモチーフにするが、数学者を嘲笑するものでも、AI を否定するものでもない。AI による数学の発展を喜ばしく思うアマチュア数学者（発行者）からの、前向きなメッセージ
- 結末の転換：「切るのは、己の矜持。生き残るのは、数学。」（What is cut is pride. What survives is mathematics.）
- キャッチコピー：「The proof was beautiful. It just wasn't ours.」（証明は美しかった。ただ、それは私たちのものではなかった。）
- 発行者の取り分を半減期でロックする設計は、論文の形式で「補題（Halving）」として提示する

過激な名前が、取引所の審査・広告・SNS でどこまで通用するかを観察する社会実験も兼ねる。

## ミーム・ビジュアル

- メインビジュアル：白装束の侍が、梅の屏風と舞う花びらの前で正座する写真（`sites/seppuku/public/hero.webp`）
- 色：白・淡いラベンダー・桜色・縞袴の灰。流血や暗さを避け、ハイセンスにまとめることで前向きさを出す
- ロゴ：証明終了の記号「∎」を、一閃で斜めに断ったもの
- サイトの構成は数学の論文の体裁（§、Definition、Lemma、Proof、∎）
